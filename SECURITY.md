# Security

Do not put API keys, session cookies, or `.dev.vars` in this repository. Tillpad secrets start with `tp_` — treat them like passwords.

This repo is a **catalog stub**. It does not accept traffic, store data, or validate keys. The hosted MCP server is [https://tillpad.dev/mcp](https://tillpad.dev/mcp).

## Reporting a vulnerability

Use in-product support or the contact listed on [tillpad.dev](https://tillpad.dev). Do not open a GitHub issue that includes a live key or customer data.

## Client configs

If you paste an MCP config into a gist, chat, or PR, replace the secret with `tp_…` first.
